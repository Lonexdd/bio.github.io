# Портфолио

Статичный сайт: чистый HTML / CSS / JS, без сборки и зависимостей.

```
index.html            разметка и весь текст (RU + EN в data-атрибутах)
assets/css/style.css  стили, палитра, стекло, курсор, адаптив
assets/js/main.js     курсор, переключатель языка, меню, анимации
assets/img/bg.jpg     обои
serve.ps1             локальный сервер (необязательно)
```

## Запуск

Просто открой `index.html` двойным кликом.
Или, если нужен нормальный `http://` (например, чтобы проверить как в проде):

```bash
powershell -ExecutionPolicy Bypass -File serve.ps1
```

и зайди на `http://localhost:5173`.

## 1. Обои

Сохрани картинку как **`assets/img/bg.jpg`** — она подхватится сама.
Пока файла нет, фон рисуется CSS-градиентом в тех же тонах, сайт не ломается.

Настройки фона — в `assets/css/style.css`, блок `.bg__image` / `.bg__veil`:

- `background-position: center 30%` — какая часть картинки видна;
- в `.bg__veil` градиент задаёт, насколько фон затемнён сверху и снизу.
  Хочешь видеть обои чётче — уменьши значения `rgba(3,7,11, …)`.

## 2. Что заменить в тексте

В `index.html` через поиск:

| Найти | Что это |
|---|---|
| `от 3 дней` / `from 3 days` | сроки в услугах — поправь под себя |
| блок `<ul class="stack">` | список технологий |
| `<li class="process__item">` | четыре этапа в разделе «Процесс» |

Контакт один — Telegram `@owncheats` (блок `.contact__tg` и `<title>`).
Личных данных на сайте нет: ни имени, ни почты, ни GitHub.

Тексты в разделе «О себе» и стек — это черновик, перепиши под себя.

## 3. Двуязычность

Каждый переводимый элемент несёт два атрибута:

```html
<h3 data-ru="Заголовок" data-en="Heading">Заголовок</h3>
```

`main.js` подставляет нужный при клике на `RU / EN` и запоминает выбор
в `localStorage`. Добавляешь новый текст — добавь оба атрибута, и всё.
Внутри атрибутов можно использовать `<br>`.

## 4. Раздел «Процесс» и будущие работы

Пока кейсов нет, на их месте стоит раздел `#process` — четыре этапа
работы. Правится как обычный текст: блоки `<li class="process__item">`,
можно добавить или убрать шаг. `style="--d:.06s"` — задержка появления
при скролле, у каждого следующего шага чуть больше.

Когда появятся работы, добавь секцию перед `#contact` и пункт в меню:

```html
<section class="section" id="work">
  <div class="wrap">
    <p class="section__num reveal">04</p>
    <h2 class="section__title reveal" data-ru="Работы" data-en="Work">Работы</h2>
    <div class="work">

      <a href="https://ссылка-на-проект" class="proj glass reveal" data-cursor="card">
        <div class="proj__thumb"><img src="assets/img/project-1.jpg" alt=""></div>
        <div class="proj__body">
          <h3 data-ru="Название" data-en="Title">Название</h3>
          <p data-ru="Одна строка о проекте." data-en="One line about it.">Одна строка о проекте.</p>
          <span class="proj__tag">Telegram Bot</span>
        </div>
      </a>

    </div>
  </div>
</section>
```

Стили `.work` / `.proj` под это лежат в `style.css` в блоке
«работы (пригодится, когда появятся кейсы)» — раскомментируй их.
Не забудь перенумеровать `.section__num` у контактов на `05`.

## 5. Курсор

Круг (`.cursor-ring`) едет за мышью с инерцией, точка (`.cursor-dot`) —
точно по курсору. Состояния задаются в CSS:

- `.is-link` — над ссылкой/кнопкой, круг растёт и золотится;
- `.is-card` — над карточкой, круг становится большим;
- `.is-down` — зажата кнопка мыши.

Чтобы элемент реагировал как карточка, повесь на него `data-cursor="card"`,
как ссылка — `data-cursor="link"`.

На тач-устройствах кастомный курсор автоматически выключается
(проверка `pointer: fine`), там остаётся обычное поведение.

## 6. Анимации

Что и где крутится:

| Эффект | Где править |
|---|---|
| Интро шапки по элементам | `html.js .logo/.header__right/.nav a` |
| Полоса прогресса сверху | `.progress` в CSS, п.7 в `main.js` |
| Заголовки построчно из-под маски | `.line` / `.line__inner`, сплит в `main.js` п.1 |
| Появление блоков при скролле | `.reveal`, задержка через `style="--d:.12s"` |
| Магнитные кнопки | `main.js`, п.5 — коэффициенты `0.22` / `0.28` |
| Свечение под курсором на карточках | `.card::after` + `main.js` п.6 |
| Линия наливается золотом в «Процессе» | `.process__item::before` |
| Пульс точки в логотипе | `@keyframes pulse` |

**Фон намеренно неподвижен**: ни параллакса при скролле, ни наезда при
загрузке, ни дрейфа зерна. Слои `.bg__image` / `.bg__veil` / `.bg__grain`
статичны — если захочешь вернуть движение, оно добавляется в `main.js`
в цикле п.7.

Общая «плавность» задаётся одной переменной — `--ease-out` в `:root`.
Хочешь резче — поставь `cubic-bezier(.4,0,.2,1)`, мягче — увеличь
длительности (`1.1s` у `.reveal`, `1.15s` у `.line__inner`).

Прогресс и курсор считаются в одном `requestAnimationFrame`
(п.7 в `main.js`), а не в обработчиках скролла — поэтому не дёргается.

Если в системе включено «уменьшить движение», всё это выключается
автоматически — блок `prefers-reduced-motion` в конце CSS.

## 7. Палитра

Все цвета — в `:root` в начале `style.css`. Основное:

```
--bg-0   #03070b   почти чёрный фон
--fog    #1e4257   синий туман с обоев
--text   #e2ecf2   основной текст
--muted  #8ba1ae   вторичный текст
--gold   #c8a45f   акцент (позвонки с обоев)
--glass  rgba(7,17,25,.42)   заливка прозрачных панелей
```

Степень прозрачности интерфейса — `.glass` в CSS: `background` (насколько
панель плотная) и `backdrop-filter: blur(18px)` (насколько размыт фон под ней).

## 8. Публикация

Любой статический хостинг. Самое простое — GitHub Pages:

```bash
git init && git add . && git commit -m "portfolio"
```

затем создай репозиторий и включи Pages из ветки `main`, папка `/root`.
